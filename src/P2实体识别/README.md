# P2正式实体识别程序

仅保留已验收的最新实现。全部47篇由同一套词典、语境约束和时间规则重新识别，不直接拼接旧17篇实体结果。

## 运行

从仓库根目录执行：

```powershell
python "src/P2实体识别/run.py"
python -m unittest discover -s tests/P2 -v
```

Python 3.11及以上；抽取使用标准库，绘图使用Matplotlib。不依赖Jieba、浏览器、Docker或在线接口。`--no-plots`跳过绘图；`--output .test_tmp/p2_check/results --figures .test_tmp/p2_check/figures`可指定测试输出。输入及正式配置通过哈希校验，运行不修改P1。

## 文件

- `src/p2_entities/config.py`：路径、配置与哈希。
- `extractor.py`：最长名称、语境判断、同源前3段上下文和原文位置。
- `time_rules.py`：完整日期、核心时间值和提示词上下文。
- `pipeline.py`：批量识别、结构校验、39项定点验收与导出。
- `candidates.py`：活动、未确定类型及省略展开候选，候选不冒充实体。
- `plots.py`：三类词频及分景区POI图。
- `config/`：唯一正式词表、时间规则、决策及验收用例；不再依赖草案或旧版本目录。

结果写入`processed/P2实体识别/`；诊断与候选在其`辅助资料/`。图表及报告在`outputs/P2/`。完整字段见[实体定义与输出规范](实体定义与输出规范.md)。

正式结果为3647次提及：POI1931、交通463、时间1253；实体文件可逐字节复现已验收结果。39项定点检查不是完整人工准确率。第三方定性意见按用户裁定的项目规范处理，质量记录与优化前后汇总见outputs/P2/质量核对记录.json及P2实验报告正文.md。

## 边界

保留步行/徒步，节目与活动不作POI；时间取核心值，提示词另存time_context。疑似错字不自动纠正，不凭猜测修改专名；OCR断行不拼接，词典外名称仍可能遗漏。词表参考过全47篇，不声称未见语料泛化或未经完整标注支持的P/R/F1。

按交付要求，旧代码、逐条预测和草案已从项目移除；只保留必要的历史汇总与代表性证据用于报告，程序不提供旧版本切换。
